# Модуль 01 — Среда выполнения и воспроизводимость notebook

## Название и цель
Проект демонстрирует понимание различия между notebook и runtime, 
умение восстанавливать порядок ячеек и создавать воспроизводимый проект.

## Состав файлов
- `notebooks/lr01_runtime_order_фамилия.ipynb` — notebook ЛР 1
- `data/sample_text.txt` — учебный текстовый файл
- `data/mini_corpus.tsv` — учебный мини-корпус
- `docs/version_log.md` — история изменений проекта

## Как открыть
1. Откройте `notebooks/lr01_runtime_order.ipynb` в Google Colab или Jupyter.
2. Запустите все ячейки сверху вниз: Runtime → Run all.
3. Проверьте, что нет ошибок NameError.

## Проверка
Проект считается воспроизводимым, если:
- Restart → Run all проходит без ошибок;
- Markdown-ячейки объясняют, что делает код;
- файлы данных доступны по относительным путям (`../data/sample_text.txt`).

## Ограничения
- Файлы в Colab временны — после закрытия runtime данные нужно загружать заново.
- Notebook сохраняет вывод, но не сохраняет состояние runtime.
- Проект не использует внешние библиотеки.
